# 附篇 · 整机榜与真机语料入门（反面教材 + 训练源）

> 整机榜：只做选型参考，不当成绩。真机语料：只做训练源，不当成绩。
> 记住三无（无实测/无审计/无冻结）与三件套（复位规定/成功检测器/冻结协议）。

---

## 一、整机榜四家（看整台人形行不行，不看单个算法）

### 1. HPS 榜（Humanoid.press）
- 谁运营：Humanoid Press（Don Kim），2026-01 上线，自媒体榜。
- 数据哪来：厂商官网、白皮书、行业备案拼凑，无一台自测。
- 怎么打分：自创百分制 HPS，六维合成：灵巧/移动/AI 认知/续航/安全/适应性。2026 版例：第一约 94.2，第二 Atlas 电动 91.8，Optimus Gen3 约 87.5，宇树 H2 约 82.1，Digit 约 79.4，Walker S2 约 77，GR-2 约 67。分数每天微更新，8 周滚动曲线涨 1.1 分——机器人没动过，只是改纸面参数。
- 为什么反面：无实测、无权重公式、无试验次数、无任务定义，价格估值部署故事混入性能分。

### 2. Biped.News 榜（四家中方法论最干净）
- 谁运营：Biped.News 团队，主打生产就绪度。
- 数据：公开证据，但只排具名客户、部署、付费试点等商业证据，不排人气。例：Digit 87 居首，Walker S 81 第二，Apollo 72 第三，Figure 03 约 66。
- 干净在三点：分视图排名（生产就绪/家用机会/读者兴趣分开）；亮权重、公式版本，观察名单剔除；亮置信度（Digit canonical 96、Apollo 88）+ 免责（公开证据不全≠认证）。
- 局限：仍无机器人小时数、无成功检测器、无第三方复跑。是舆情证据榜，当市场线索，不当验收。

### 3. humanoid.guide 整机库（数据库，不是榜）
- 收录 239 台左右，按身高/负载/价格/国家过滤，点进去是参数页对比图，无统一打分。数据来自厂商提交 + 编辑更新，捆绑市场报告与撮合收费。本质选型黄页。

### 4. AwesomeAgents 机器人榜（唯一尊重文献的二次聚合）
- 排大脑（VLA 模型），数据来自论文 + 公司博客，汇总 CALVIN/Simpler/LIBERO/RoboCasa 仿真分 + 真机成功率。例：CALVIN 四连 GR00T N1 微调约 3.5 居首、pi0 约 3.3；真机 pi0.5 家庭多任务 75~80%（9 类 × 30+ trial，唯一可比）、Octo 在 WidowX 约 56%、OpenVLA 在 Bridge 约 47%。
- 作者自带警告：星号数为公司博客自报（Helix 约 67%*），特斯拉 Optimus、1X Neo、Sanctuary 无成功率只有演示视频，不可比；sim 与 real 不得直接比；微调虚高注意。运营者为金融转行分析师，无自有运行。当论文地图，不引用为成绩。

**三无总结：** 无实测（HPS 纸面分）、无审计（自报星号）、无冻结（持续更新无版本）。立项评测必须自建冻结任务 + 成功检测器 + 独立复跑。

## 二、真机语料四家（人遥操录示范，只管学，不管分）

### 1. AgiBot World（智元，最大）
- 谁采：在 4000㎡ 1:1 五大场（家/零售/工业/餐饮/办公）采，100 台同构 G1 移动双臂人形 + 六维灵巧手 + 视触觉。
- 多大：超 100 万条、2976 小时、217 任务、87 原子技能（系带/开罐/剥皮/扫地…）、106 场景；单条多 30~60s、最长超 2min。
- 格式：原生 HDF5 + 视频 + 语言标注，可转 RLDS/LeRobot。CC BY-NC-SA，禁商用。
- 闭环考：无，只有论文自测（如收餐桌提升约 30%）。技能例：冲咖啡（拿杯→倒水→递送）。
- 可转性中高：key_frame 可挖任务定义，需自补检测器；本体单一，跨本体需映射。

### 2. DROID（场景最多样）
- 谁采：伯克利等牵头，50 采集员 12 个月在欧美亚 52 栋楼游采。
- 多大：7.6 万条、350 小时、564 场景、86 类动词，强调多样而非条数。
- 本体：统一 Franka 单臂 + 腕相机 + 双外部立体相机，15Hz。官方 RLDS（TFRecord 分片），另有 HDF5 + MP4，社区有转 LeRobot v3 教程，全量约 1.7TB。
- 闭环考：薄，仅论文 6 自家任务共训比单训高 22%，跨场景高 17%。任务例：关华夫饼机、苹果放锅（考换厨房换视角）。
- 可转性中：最适合预训练 + 鲁棒源；转评测需复刻 Franka + 相机位姿。

### 3. BridgeV2（最易复现）
- 谁采：伯克利 RAIL，4000 美元 WidowX 250 六轴臂 + VR 遥操，5Hz、平均 38 步/条。
- 多大：6 万条（5 万人工 + 9731 脚本乱采），24 环境（多为玩具厨房），13 技能、100+ 物体。
- 格式：原生 JPEG 分包，TFDS 有 RLDS 版，一键可转 LeRobot。
- 闭环考：实验室复现式，自家 WidowX 测 6 种模仿算法（Octo 微调约 56%，OpenVLA 约 47%），换实验室光照相机就变。任务例：胡萝卜放锅、扫豆子、叠布、开抽屉放叉子。
- 可转性高：低成本 + 开源控栈 + 检测脚本最完整，适合桌面基线层；局限任务粒度小、单臂。

### 4. OpenX（拼凑聚合，跨本体源）
- 谁拼：21 家机构 34 实验室，把 60 老数据集洗成统一格式。
- 多大：140 万条+、22 本体（臂/双臂/四足）、约 311 场景、527 技能，Franka 最多。
- 格式：只有 RLDS，LeRobot 需二次转换且动作难对齐。
- 闭环考：无，只有 RT-1-X/RT-2-X 抽查（如 Bridge 13%→50%，谷歌机 73%~91%）。任务例：桌面听指令拿可乐罐（考跨本体正迁移）。
- 可转性中：适合预训练混合 + 跨本体迁移测试，噪声大，必须叠基准才有可比性。

**转评测统一缺三件套：** 复位规定（摆哪/多亮）+ 成功检测器（谁判成败）+ 冻结协议（版本/次数/种子）。缺一个只能当训练源。

**立项一句话：** 本项目语料仅作预训练与共训源，成绩只认自建冻结闭环场三次复测成功率，语料自带数字一律不计入验收。
