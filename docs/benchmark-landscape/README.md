# 具身智能榜单全景分析 · 团队知识库

> 定位：独立评测机构的规则底座。首期纯仿真，仿真定分级，真机等实验室到位再加抽检。
> 维护：本目录随榜单更新而月更，冻结任务集变更需走评审。

## 阅读路径（新人按此顺序）

1. `01-科普篇.md` —— 11 个榜单入门：每榜七段式（是什么/任务举例/数据本体/指标数字/上手/局限/对我们的意义），先读一~三章单臂三杰，再读场景双臂，最后读统一新贵。
2. `04-整机榜与语料入门.md` —— 反面教材 + 训练源：三无榜为什么不当成绩，语料为什么只训练不算分。
3. `02-技术篇.md` —— 对比大表 + 三张自研考卷草案（拧螺丝/叠衣/上下料）+ 锚定分 + 防刷清单。
4. `03-立项衔接.md` —— 给云厂商的一页：双分披露 + 共建流程。

## 一句话结论

- 可直接借公信力：LIBERO + CALVIN 链长 + SimplerEnv + RoboTwin Easy/Hard 做锚定分。
- 必须自研：拧螺丝（扭矩）、叠衣（平整度）、上下料（节拍/联锁），现有榜单全无覆盖。
- 绝不学：HPS/Biped/humanoid.guide 式无实测打分榜；语料（AgiBot/DROID/Bridge/OXE）只做训练源，不当成绩。
