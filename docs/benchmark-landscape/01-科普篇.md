# 上篇 · 科普篇（一榜一页，全员必读）

## 一、仿真操作 7 雄（唯一有实测的，伙伴认的）

### 1. LIBERO —— VLA必报，锚定首选
UT Austin，NeurIPS 2023。130任务：Spatial/Object/Goal各10 + LIBERO-100。单臂Franka + Robosuite + MuJoCo。指标：成功率（每任务10 episode × 4套件，建议3 seed）。许可MIT，全demo开源。局限：纯单臂桌面刚体，无拧螺丝/叠衣/上下料。

### 2. CALVIN —— 长程链鼻祖
Freiburg，RA-L 2022最佳论文。34原子任务，ABCD四环境（训ABC测D）。单臂Franka + PyBullet。指标：MTLC单任务成功率 + LH-MTLC链长（0-5连续指令）。局限：同上，无工业任务。

### 3. SimplerEnv —— 排名金标准
Stanford/Google DeepMind，CoRL 2024。不是训练集，是real-to-sim评估协议，复刻Google Robot + WidowX真机。SAPIEN + ManiSkill底座。指标：成功率 + MMRV/Pearson（仿真排名与真机排名一致性）。局限：只做刚体桌面，声明不支持布/水。

### 4. RoboCasa / RoboCasa365 —— 家务头部
UT Austin，RSS 2024 → ICLR 2026。100→365任务，2500场景3200物体，2200+小时轨迹。单臂Franka为主 + Robosuite。指标成功率。叠衣仅边缘触及，无制造任务。

### 5. ManiSkill2/3 —— 技能最广
UCSD，ICLR 2023。20任务族2000物体400万帧，单/双臂/移动/灵巧手全覆盖。SAPIEN + GPU MPM软体。指标：seen/unseen成功率。虽有软体（面粉/面团/布）和插入类，但无标准拧螺丝扭矩卷、无叠衣平整度、无上下料节拍。

### 6. BEHAVIOR-1K —— 家务天花板
Stanford，CoRL 2023。1000活动50场景9000物体，移动双臂Tiago。OmniGibson + PhysX 5。指标：成功率 + 成功分Q + 效率三件套。零样本端到端全败（0%），太重难跑。无制造任务。

### 7. RoboTwin 2.0 —— 国产双臂最热
上AI Lab + 交大等，50双臂任务，731实例147类，10万+轨迹。5种双臂（Franka/Piper/UR5/ARX/AgileX）。指标：Easy/Hard成功率。局限：仍是桌面双臂刚体协作，无移动基座、无扭矩闭环、无叠衣考卷。

## 二、统一新贵 4 个（抄作业对象）

### 8. RoboDojo —— sim+real统一标杆
HKU MMLab 2026-07。42仿真（泛化/记忆/精度/长程/开放词五维）+ 18真机。XPolicyLab统一接入，一次适配多处评测。RealEval：标准化工位 + overlay复位 + 三人双盲打分 + 视频公开 + 隐藏layout防刷。结果很 sober：最优仿真仅8.8%，真机12.8%，人类76-100%。许可注意：非商业研究许可，商用需书面授权。

### 9. RoboBench —— 大脑认知评测
北大+智源+复旦，ECCV 2026。5维14能力25任务6092 QA，大脑（System2）与小脑分开评。纯API评测，成本低。感知分与CALVIN长程 r=0.88。借鉴：MCQ便宜预筛 + DAG规划精评。

### 10. vla-evaluation-harness —— 统一管线
AllenAI 2026-03。聚合14+基准，Benchmark进Docker + 模型uv单文件server + WebSocket，serve+run两命令，O(N+M)。榜单2456模型×18基准。直接复用：Dockerfile模板、record/merge、47×加速（LIBERO 2000 episode 14h→18min）。

### 11. 人形基础模型榜 —— 只做黄页
humanoid.guide 40模型×10维（运动/全身/双臂/灵巧/导航/推理/sim2real/跨本体/实时/长程）。无实测、无代码、无seed，主观打星 + 卖报告。只抄它的10维词表和过滤器UI，不学打分。

## 三、整机榜 4 个（反面教材，三无：无实测/无审计/无冻结）

- HPS（humanoid.press）：厂商白皮书拼100分，周涨跌像调参。
- Biped.News：方法论最干净（明确写不是采购认证），但仍是舆情证据榜，无机器人小时数。
- humanoid.guide整机库：选型黄页 + 咨询变现。
- AwesomeAgents：论文数二次聚合，唯一尊重文献的，但无自有运行。

教训：立项评测必须自建冻结任务 + 成功检测器 + 独立复跑，否则就是下一个不知名榜单。
