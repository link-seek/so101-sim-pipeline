## 一、LIBERO —— VLA统考卷，锚定首选

**是什么：** UT Austin 做的仿真操作基准（NeurIPS 2023），本为终身学习设计，现成所有 VLA 论文必报项（Octo、OpenVLA、π0、GR 系列）。便宜、稳定、可复现。官网 `libero-project.github.io`，仓库 `Lifelong-Robot-Learning/LIBERO`，论文 `2306.03310`。

**任务长啥样：** 单臂在桌面做拿放开合，共 130 任务，VLA 常考 40 个：Spatial 10 + Object 10 + Goal 10 + Long 10。
- Spatial 考空间关系：物体相同只变位置，如“把盘子和奶盅之间的黑碗放到盘子上”vs“把炉子上的黑碗放到盘子上”，差半句介词。
- Object 考认物体：动作都是拿起放篮子，物体换成番茄酱、奶酪盒、巧克力盒、汤罐。
- Goal 考意图：场景物体全同，指令变，如对同一套抽屉和碗：打开抽屉 / 把碗放进抽屉 / 关上抽屉。
- Long 长程综合：如先开柜门拿碗放盘子，再拿牛奶倒进去，一次五六步。

**数据与本体：** Franka Panda 单臂 + 平替夹爪，Robosuite + MuJoCo 仿真，BDDL 定义任务。每任务 50 条人工遥操作示范。动作 7 维（末端增量 + 夹爪），观测为第三视角 + 腕部 RGB（128/256）+ 本体感知 + 一句英文指令。

**指标咋看：** 只看成功率。OpenVLA 协议每任务跑 50 次。代表数字：OpenVLA-OFT 四套件平均约 97%，Long 约 94.5%；从零训的扩散策略 Spatial 仅约 70%；Octo 零样本约 0%。判读线：单套件 90%+ 算可用，四套件平均 95%+ 跟上 SOTA，Long 低于 90% 说明长程不行。

**上手路径：** 建 conda 环境并 `pip` 装 libero 包 → 跑 `benchmark_scripts/download_libero_datasets.py` 拉数据（或 HuggingFace 版）→ 用 `libero/lifelong/main.py` 选 benchmark/policy/algo 训练，或直接用 LeRobot `lerobot-eval`（env.type=libero）评已有检查点。

**局限：** 全是刚体准静态桌面拾放，无柔性布料、无力控、无 6D 小公差装配、无移动底盘。碗放歪也算成，真拧螺丝差 1mm 就滑牙——仿真里没建模。

**对我们意义：** 主力锚定分。固定四套件各 50 次协议，每次改模型跑一遍，看平均值 + Long 单项，既对论文数字，也防回归。

## 二、CALVIN —— 长程连续干活考，专管泛化

**是什么：** 弗莱堡大学做的语言条件长程基准（RA-L 2022 最佳论文），考模型能否听懂连续多句人话连续干活。RoboFlamingo、GR-1、MDT、UniVLA、FLOWER 等讲长程必报。官网 `calvin.cs.uni-freiburg.de`，仓库 `mees/calvin`（+`calvin_env` 子模块），论文 `2112.03227`。

**任务长啥样：** 永远一张桌子 + 一台 Franka，桌上有滑动门、抽屉、按钮（按亮绿灯）、开关（控灯泡）、三色方块。A/B/C/D 四个房间，纹理与物件位置不同，训 ABC 测 D 即零样本泛化。原子任务 34 个：开抽屉、关滑动门、按亮绿灯、拨开关、拿蓝块、推红块到左、叠块、放块进抽屉等。长程链把 34 任务随机串成 5 句一组（如开抽屉→拿蓝块→放进抽屉→关抽屉→推滑块到左），共 1000 条链，回中立位开始，错一步整链断。

**数据与本体：** 7 自由度 Franka + 夹爪，PyBullet，30Hz 闭环。数据是约 24 小时 VR 无脚本玩耍（含失败重试），状态机自动打标，仅约 1% 配人工 389 种说法。语言默认 MiniLM 转 384 维。动作三选一（绝对/相对笛卡尔/关节 + 夹爪），观测为静态 200×200 RGB-D + 腕部 84×84 RGB-D + 触觉 + 本体，可自由组合。

**指标咋看：** 双轨：MTLC（34 任务各 10 次平均成功率）+ LH-MTLC（1000 链，能连做 1/2/3/4/5 个的比例，平均链长 Avg.Len 0~5）。代表数字：最早 MCIL 在 D 训 D 测仅 0.64；HULC 2.64；RoboFlamingo 全量 ABCD 训 D 测单步 96.4%、5 连做 66%、平均 4.08，换 ABC 训 D 测掉到 2.47；现顶流 MDT 约 4.52、UniVLA 约 4.63。判读线：平均 3 以下入门，4 以上好，全量与零样本差 <0.5 说明真泛化。

**上手路径：** `clone --recurse-submodules` → `sh install.sh` → `sh download_data.sh` 选 D/ABC/ABCD/debug → 训练跑 `training.py` 选观测动作配置 → 评测跑 `evaluation/evaluate_policy.py`，自研模型实现 reset/step 接口即可挂入。

**局限：** 纯色方块，无螺纹卡扣布料，触觉简化，无真实力反馈与打滑；永远一张桌子，无导航与工厂节拍。考不了拧螺丝/叠衣/上下料。

**对我们意义：** 第二锚定，专管长程与泛化。固定报 ABCD 训 D 测 Avg.Len（看上限）+ ABC 训 D 测（看真泛化）。缺点是 PyBullet+EGL 环境老安装坑多，适合周级跑。

## 三、SimplerEnv —— 真机替代考场，排序器

**是什么：** Stanford/UT Austin/Google DeepMind 做的 real-to-sim 评估协议（CoRL 2024），不做训练集，只做评测。思路不是把仿真做逼真，而是让仿真排名与真机一致，RT-1/X、Octo 选检查点用它。官网 `simpler-env.github.io`，仓库 `simpler-env/SimplerEnv`，论文 `2405.05941`。

**任务长啥样：** 复刻两套真机。谷歌套：拿可乐罐（横/竖/立三分）、拿任意物体、可乐罐移到橙子旁、开顶/中/底抽屉、关抽屉、苹果放进关闭的顶层抽屉。WidowX 套：勺子放毛巾、胡萝卜放盘子、绿块叠黄块、茄子放篮子。全是仿真算得准的短程刚体任务，每任务大量位姿/光照/背景变体。

**数据与本体：** 不提供训练数据。SAPIEN + ManiSkill2（有 ManiSkill3 GPU 加速版快 10 倍+）。谷歌 3Hz、WidowX 5Hz，仿真 500Hz，Gym 接口。动作末端增量 + 转轴角 + 夹爪。两招缩差距：视觉匹配（绿幕贴真背景 + 材质对齐）+ 控制标定（少量真机轨迹做系统辨识）。

**指标咋看：** 核心是仿真与真机同涨同跌：MMRV（0~1，越低越好，排错名的真机分差，排错强弱罚重、排错相近几乎不罚）+ Pearson（-1~1，越高越好）。代表数字：视觉匹配版 MMRV 约 0.056、Pearson 约 0.924；看验证集 loss 选模型则是 0.375/0.308——证明跑仿真远胜看 loss。单看成功率：GR00T 谷歌六类平均约 67.6%（拿罐 97.5% 但苹果进关闭抽屉仅 14.5%）；WidowX 平均约 62%，叠块仅 5.5%。

**上手路径：** python3.10 环境 → `pip` 装 `ManiSkill2_real2sim` + `simpler_env`（完整评测再装 tensorflow 与 Octo 依赖）→ 跑示例脚本做视觉匹配预打包环境，或用 scripts 扫位姿做论文级复现 → `tools/calc_metrics.py` 算 MMRV/Pearson。

**局限：** 故意只挑仿真算得准的刚体短任务，柔性、细公差、大力接触、移动全砍。分高只代表真机排名大概率高，不代表真机一定行。考不了拧螺丝/叠衣/上下料。

**对我们意义：** 真机前锚定：定谷歌拿取 + WidowX 放物约 10 任务为冒烟集，只看两件事——仿真成功率掉没掉、与历史真机点的 MMRV 还低不低。当筛子用，不当能力天花板。

## 四、RoboCasa / 365 —— 厨房通用管家考

**是什么：** UT Austin Yuke Zhu 团队做的家用移动操作大仿真（RSS 2024 → ICLR 2026），多任务与基础模型团队在用。官网 `robocasa.ai`，仓库 `robocasa/robocasa`。

**任务长啥样：** 全在厨房，机器人推移动底座做家务。原子（单技能）：开微波炉门、开关抽屉、按咖啡机按钮、插拔插头、拧旋钮。复合（一串）：做咖啡（开柜拿杯→放机下→按按钮）、烧水、烤面包、洗碗、收剩菜，共 60 类高管活动。365 = 65 原子 + 300 复合（220 要导航，145 原地）。每步标子任务与 pick/place/navigate 阶段，适合层次策略。

**数据与本体：** 2500 套按美国真实厨房建的场景，3200+ 物体。2200 小时：612 小时人工遥操 30k 条 + 1615 小时 MimicGen 自动扩增。本体默认 Franka + Omron 底座，也支持人形。动作末端增量 + 夹爪 + 底座速度。Robosuite + MuJoCo，照片级渲染。

**指标咋看：** 成功率对 50 个目标任务平均，分三档：Atomic-Seen（见过短技能，最易）、Composite-Seen（见过长任务）、Composite-Unseen（未见长任务零样本，最难）。代表数字：GR00T N1.5 平均 20%（原子 43%、见过复合 9.6%、未见 4.4%）；Diffusion Policy 仅 6.1%；榜首小米方案 57.4%（80.2/57.1/32.1）。长程一难掉一个数量级。

**上手路径：** 装 robosuite master → 跑官方 Basic Usage → 从 HuggingFace 下 Human300 预训练集 → 一条命令训 Diffusion Policy 或 pi0 → `eval_robocasa.py` 指定三档在 pretrain 场景打分，可投 leaderboard。

**局限：** 只做厨房。拧螺丝边缘沾边（有插入、拧旋钮，无螺纹扭矩）；叠衣不沾（全刚体）；上下料不沾（无机床料盘节拍）。

**对我们意义：** 长程泛化锚定，直接抄三档划分法；移动取放逻辑与语言条件管线值得抄，场景不直接借。

## 五、ManiSkill2/3 —— 技能基本功训练馆

**是什么：** UCSD 苏浩团队基于 SAPIEN 的可泛化技能基准（ICLR 2023），专治“换物体形状就崩”。RL、模仿、点云视觉必用。官网 `maniskill.ai`，仓库 `mani-skill/ManiSkill`。

**任务长啥样：** 单桌短技能，换物体测泛化。插入族 PegInsertionSide（孔隙 2~3mm，最考精度）、PlugCharger 插充电器；软体族 Excavate 铲土、Pour 倒水、Pinch 捏橡皮泥（刚柔双向 MPM）；杂物族 PickCube、PickClutterYCB 杂堆取物、StackCube。ManiSkill2 为 20 族 2000+ 物体 400 万帧，ManiSkill3 扩到 12 域（含四足/人形/灵巧手/移动）。

**数据与本体：** 演示来自规划、RL、遥操。支持 20+ 本体：Franka、UR5e、xArm、Fetch、Unitree H1、Shadow Hand。动作统一关节位置或末端 IK 增量 + 夹爪。自研 SAPIEN（PhysX + Vulkan 并行，4090 上 RGBD 采集 3 万 FPS，128 并行仅 4.4G 显存），支持异构并行每环境不同物体。

**指标咋看：** 成功率二值判定（如销子全插入、方块距目标 2.5cm 内）。惯例易 = 见过物体位姿，难 = 未见物体 + 杂物 + sim2real 数字孪生。代表数字：PickCube 状态 PPO 几分钟近 100%，视觉 PPO 需 GPU 并行；PegInsertion 点云 BC 约 30~60%，换未见 peg 掉 20 个点以上。

**上手路径：** `pip` 装 `mani_skill`（v0.5.3 = ManiSkill2，3.0+ = ManiSkill3）→ `download_asset/download_demo` 下 PickCube 资源演示 → 跑 Colab quickstart → 跑 PPO/BC 基线。

**局限：** 多为单臂桌面。拧螺丝边缘沾（插入精度可迁移，无螺纹拧紧力控）；叠衣边缘沾（软体是面团流体，非大布料折叠）；上下料不沾（无双臂协作、无托盘机床）。

**对我们意义：** 底层技能锚定：借 PegInsertion 测拧螺丝前精度，借 Pour/Pinch 看柔性功底，点云 RL 管线直接复用。

## 六、BEHAVIOR-1K —— 千题长考（方法抄，不跑分）

**是什么：** Stanford 李飞飞/吴佳俊团队以人为中心基准（CoRL 2023）：先问卷“最想机器人干什么”再定 1000 题，做长程规划用。官网 `behavior.stanford.edu`，仓库 `StanfordVL/BEHAVIOR-1K`。

**任务长啥样：** BDDL 谓词逻辑定义初末态，可无限随机初态。50 场景（住宅/花园/餐厅/办公室），9000+ 物体带物理语义。例：CleanTable（擦桌收垃圾入桶）、CollectTrash（多房间巡回收）、StoreDecoration、做晚饭、拖地、刷浴缸。动辄几十步，导航操作交替，有记忆才不走回头路。

**数据与本体：** 主体是知识库 + 资产（非轨迹集），另有 JoyLo/VR 遥操演示。本体为移动臂（Fetch/Tiago/Franka + 底座），动作含底层关节底座速度与上层 navigate/pick/place 原语（CuRobo 加速）。OmniGibson（Omniverse + PhysX5，刚体/可变形/流体/光追 + 温度/浸湿/脏污/开关扩展态）。

**指标咋看：** 主分 Q = 满足的目标谓词比例（多选目标取最大），Q=1 才算成功；效率看相对人类最优的导航距离/仿真时间/运动扰乱。代表数字：端到端视觉 RL 全 0%；加原语后 StoreDecoration 46%、CollectTrash 36%、CleanTable 73%，加记忆再涨 4~6%；开全物理抓取掉到近 0%（抓取是瓶颈）。

**上手路径：** 装 OmniGibson（Omniverse 依赖重，需高端 GPU）→ 下资产 → 跑 `behavior_env_demo.py` → 用 BDDL 任务采样评测。

**局限：** 纯家务，无螺丝；叠衣边缘沾（有 folded 态但启发式）；上下料仅逻辑可借（取放导航与扰乱度），无节拍精度。且太重太慢，不宜当天天跑的锚定。

**对我们意义：** 不做锚定，抄方法：BDDL 谓词成功定义 + 三项效率指标，直接用来评上下料全流程。

## 七、RoboTwin 2.0 —— 双臂协作考场（国产最热）

**是什么：** 上海 AI Lab 等做的双臂基准（论文 `2506.18088`，投 ICML 2026），专治双臂数据难扩与仿真太假。双臂 VLA 团队在用。官网 `robotwin-platform.github.io`，仓库 `RoboTwin-Platform/RoboTwin`。

**任务长啥样：** 桌面双臂，三相机 + 语言指令，50 题跨 5 本体。协作例：HandoverBlock/HandoverMic（一臂拿起空中递交另一臂放下）、LiftPot（双臂同步抬锅）、PlaceDualShoes（双手各放一只鞋）、StackBlocks（三块叠塔）、BeatBlockHammer（一扶一敲）、DumpBinBigbin（双人倒箱）。

**数据与本体：** RoboTwin-OD 731 实例 147 类；大模型写代码 + 仿真闭环修正自动产 10 万+ 轨迹；基准固定每题 50 条干净演示。本体基准 Aloha-AgileX 双 14 自由度，另有 Franka/Piper/UR5/ARX-X5，夹爪 Panda/WSG。动作 14 维双臂关节归一到 -1~1。仿真器 SAPIEN，头顶 + 左右腕三相机。

**指标咋看：** 成功率 = 100 轮成功占比。Easy（clean2clean）/ Hard（clean2random + 五轴随机：杂物/光照/背景/台面高/语言改写），排名用平均分 =（易 + 难）/2。代表数字：简单放物易 60~90%，难掉 20~40 个点；合成 + 10 条真机比纯 10 条真机相对提升 367%，纯合成零样本仍涨 228%。

**上手路径：** 按 doc 装环境下 OD 资产 → `collect-data.py` 采 HandoverBlock → 用 XPolicyLab 训 ACT/Diffusion/RDT/Pi0 → 易难各 100 轮评 → 联系作者投 leaderboard。

**局限：** 纯桌面双臂。拧螺丝边缘沾（StampSeal 盖章、PressStapler 有按压，无拧紧）；叠衣不沾；上下料不沾（PlaceObjectBasket 似摆盘，无 CNC/安全门/节拍）。

**对我们意义：** 双臂锚定：借 Handover/LiftPot 测交接同步，借五轴随机测鲁棒；更可借其大模型自动写专家代码管线，低成本扩拧螺丝与上下料新题。

## 八、RoboDojo（含 RealEval）—— sim+real 统一标杆

**是什么：** 2026-07 通用操作策略榜（HKU MMLab 等 43 作者，`2607.04434`），专治“题太简单、只考一边、没法复现”。42 仿真 + 18 真机，30+ 策略同场。官网 `robodojo-benchmark.com`，仓库 `RoboDojo-Benchmark/RoboDojo` + `XPolicyLab`。

**机制：** 仿真 42 题按五维出题：泛化 12、记忆 6、精度 8、长程 8、开放词 8（Isaac Sim 5.1/IsaacLab 异构并行）。真机 18 题 = 3 双臂平台（ARX X5/Piper/Piper X）× 各 6 题，每题 10 次共 180 trial。XPolicyLab 统一插座：策略写一次适配器（`eval.sh + deploy.yml`，声明观测动作格式与端口），仿真真机走同一 Web 接口，依赖隔离，本地/远程 GPU 可切。RealEval 远程真机：标准工位（结构件锁死臂/相机/灯光/台面）+ 触屏管复位急停录像打分 + overlay 复位（目标布局半透明叠实时画面对齐）→ 云端提交容器 → 按 overlay 复位 → 跑 10 次全程录像 → 3 人双盲打分（成功率 + 步骤分取平均），视频公开可申诉。

**例子：** 叠碗考精度维；清理杂物桌考长程 + 记忆；真机折叠抹布专考接触丰富与感知噪声（仿真难模拟的坑）。

**榜单数字（sober）：** 仿真最强 HY-Embodied-0.5-VLA 平均成功率仅 8.8%（人类同协议 76.03%）；真机最强 π0.5 仅约 22.9 分/12.8%。题对人可行、对 VLA 极难，不是刷分榜。

**许可成本：** RoboDojo 非商业研究许可（科研教育可，商用书面授权）；Isaac Sim 源码 Apache-2.0 内部研发免费，对外仿真服务/分发 Omniverse Kit 应用需买 NVIDIA AI Enterprise。自建异构并行要大显存 GPU。

**抄什么：** 容器化接入抄 XPolicyLab；盲测抄三人双盲 + 录像公开；远程复核抄标准工位 + overlay + 云端提交。

## 九、RoboBench —— 只考大脑的选择题榜

**是什么：** 北大 + 智源 + 复旦（ECCV 2026，`2510.17801`），专治“只看抓没抓到，不知大脑笨还是手笨”。流行大脑小脑分离：大脑（多模态大模型：理解/看/规划），小脑（VLA/扩散：输出关节）。RoboBench 只考大脑，6092 道问答，不用真机。官网 `robo-bench.github.io`，仓库 `yulin-luo/RoboBench`。

**机制：** 五维对操作流水线：指令理解（显式“拿红杯”/隐式“我有点渴”）、感知推理（物体属性/空间/时间因果/机器人视角）、泛化规划（跨本体/物体/视角/任务）、可供性预测（“杯把哪可抓”、轨迹画哪、移动基座）、失败分析（看失败视频说是位置偏还是规划错）。共 14 能力 25 任务。精髓是 DAG 规划评测：长程任务人工标有向无环图（如开抽屉→拿苹果→放盘子），大模型当世界模拟器逐步推演规划，看里程碑（抽屉 = 开、苹果在盘上）达成，分节点正确率 + 任务完成率；另有下一步预测（技能/物体/参数）与子任务完成二分类。

**例子：** 遮挡场景给多视角图考跨视角；双臂图考能否说“左手扶右手拧”而非单臂动作。

**榜单数字：** 18 前沿模型，Gemini-3.1-Pro 最稳（感知约 67.3、可供性 85.7、失败 53.0）；闭源平均领先开源约 20 分（指令差 28、规划差 25 最宽）；纯文本基线感知仅 27（必须真看图）；隐式指令比显式掉 30%；执行级错误诊断最难，最好仅 43.7。感知分与 CALVIN 长程 r≈0.88，可做选型依据。

**许可成本：** 代码数据公开，选择题零硬件；Q1 规划打分调评估大模型 API 有 token 花费；数据多源自真实机器人集，自用注意原许可。

**抄什么：** 低成本筛大脑：DAG + 世界模拟器做可解释规划分，不买机械臂也能发现“想得美做不到”的感知-动作鸿沟。

## 十、vla-evaluation-harness —— N×M 变 N+M 的转接头

**是什么：** AllenAI 通用跑分器（2026-03，`2603.13966`），专治“每加一模型/一榜调一遍依赖装一堆素材”。官网文档站 + 榜单 `allenai.github.io/vla-evaluation-harness`，仓库同名，`pip` 包 `vla-eval`。

**机制：** 两条命令。`vla-eval serve --config 模型.yaml` 在主机 GPU 起模型服务，模型文件是带 PEP723 声明的 uv 单脚本，`uv run` 自动隔离环境（CogACT 要 transformers 4.40 与 X-VLA 要 4.44 可共存）。`vla-eval run --config 榜.yaml` 在 Docker 里跑榜环境，WebSocket+msgpack 传观测动作。模型实现 `predict()`，榜实现 reset/step 四方法，任意搭配即通。14 仿真榜各打镜像 3~36GB（LIBERO/CALVIN/Simpler/RoboTwin/RoboCasa365 等），版本场景纹理锁死，ghcr 直接拉。episode 分片 + 批量推理 47×：LIBERO 2000 条从 14h 压到约 18min。结果存 JSON（harness 版本/种子/题单），精确复现；聚合 657+ 已发表成绩做总榜。

**例子：** `serve lerobot/pi05_libero.yaml` + `run libero/object.yaml` 测 π0.5 物体泛化；换 `serve xvla/simpler_widowx.yaml` + `run simpler/widowx` 切 SimplerEnv，不改代码。

**许可成本：** harness 本体 Apache-2.0，但镜像各榜许可跟走：RLBench/BEHAVIOR/RoboDojo 等锁镜像需本地构建并守原非商业限制。36GB 大镜像 + 渲染 GPU 是主要成本。

**抄什么：** 容器化接入照抄：模型侧 uv 隔离、环境侧 Docker 锁死、双 YAML 驱动、结果 JSON 存证，内部榜从 O(N×M) 降到 O(N+M)。
