## 二、行业映射与空白（必须自研，三张考卷草案）

- 制造 · 拧螺丝：现有榜单全无（无螺纹/扭矩/滑牙）。考卷草案：M4/M6 螺钉 + 扭矩阈值 + 圈数计数 + 滑牙/歪斜判负；域随机：油污、振动、来料位姿；指标：一次成功率 + 平均拧紧时间 + 滑牙率（越低越好）。精度前置可用 ManiSkill PegInsertion（2~3mm 孔隙）做预筛。
- 家政 · 叠衣：仅边缘（ManiSkill 面团流体、BEHAVIOR folded 启发式、RoboCasa 未覆盖）。考卷草案：浴巾/T恤两类 + 平整度（褶皱面积比）+ 角对齐误差 + 步骤数；域随机：布料材质/颜色/初始褶皱。注意仿真器选型：刚体仿真器做不了，必须用布料仿真（ManiSkill MPM 或等效）。
- 制造 · 上下料：全无（无夹具公差/节拍/安全门/联锁）。考卷草案：托盘取料 → 机床装夹 → 关门 → 开门取件全流程；BDDL 式谓词成功定义（抄 BEHAVIOR-1K）+ 三项效率（导航距离/节拍/碰撞次数，碰撞零容忍一票否决）；域随机：来料位姿、托盘满空、光照。
- 通用缺口：现有榜单桌面刚体为主，不考移动基座 + 双臂 + 力控全流程——这正是云客户愿意付费的差异点。

## 三、锚定分方案（借公信力，双分披露）

- 锚定分（证明不是野榜，伙伴可换算）：LIBERO 四套件成功率（主力） + CALVIN LH-MTLC 链长（长程，周级） + SimplerEnv Visual-Matching 成功率/MMRV（真机前冒烟） + RoboTwin Easy/Hard（双臂）。
- 行业分（真价值，自研三考卷）：冻结任务集 + 复位程序 + 自动成功检测器 + 3 seed。
- 上报规范：3 seed 均值 ± 方差；仿真全量排名只看仿真；真机（实验室到位后）只做 10% 抽检验真伪；单次排名不发布，只发胜任等级 + 场景画像。

## 四、防刷与复现机制（抄作业清单）

1. 管线抄 harness：Benchmark 进 Docker 版本化 + 模型 uv 单文件 server + serve/run/merge 三命令，结果 JSON 存证（版本/种子/题单）。
2. 契约抄 XPolicyLab：观测/动作/轨迹统一 schema + predict/reset/batch 最小接口，依赖隔离，本地/远程同一适配器。
3. 盲测：测试种子不公开 + 隐藏 layout + 跨本体全量测（缺一不上榜）。
4. 存证：录像 + 原始数据存档 + 配置 checkpoint 全公开 + 一次申诉复测。
5. 认知预筛（可选，降成本）：RoboBench MCQ 便宜筛大脑，DAG 规划精评，再进全量仿真。
6. 远程复核（实验室到位后）：标准工位 + overlay 复位 + 三人双盲 + 视频公开（抄 RealEval）。

## 五、语料定位（只做训练源，不当成绩）

- AgiBot World（100万轨/双臂人形/HDF5→LeRobot）：key_frame 可挖任务定义，需自补检测器；CC BY-NC-SA 禁商用。
- DROID（76k/Franka/RLDS）：预训练 + 鲁棒源；转评测需复刻硬件。
- BridgeV2（60k/WidowX/TFRecord）：最易复现的桌面基线层；任务粒度小。
- OXE（100万+/跨本体/RLDS）：跨本体迁移测试源，噪声大，必须叠基准。
- 铁律：语料自带数字一律不计入验收（细则见 04）。
