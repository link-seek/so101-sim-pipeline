## 二、行业映射与空白（必须自研）

- 制造 · 拧螺丝：全无。需补扭矩/圈数/滑牙检测 + 油污振动域随机。
- 家政 · 叠衣：仅边缘。需补平整度/角对齐度量 + 布料域随机。
- 制造 · 上下料：全无。需补节拍 + 夹具公差 + 安全门联锁 + 碰撞零容忍。
- 通用缺口：现有榜单全是桌面刚体为主，不考移动基座 + 双臂 + 力控全流程。

## 三、锚定分建议（借公信力，双分披露）

- 锚定分（证明不是野榜）：LIBERO四套件成功率 + CALVIN LH-MTLC链长 + SimplerEnv Visual-Matching成功率/MMRV + RoboTwin Easy/Hard。
- 行业分（真价值）：自研考卷，冻结任务集 + 复位程序 + 自动成功检测器。
- 上报规范：3 seed均值±方差；仿真全量排名只看仿真；真机（实验室到位后）只做10%抽检验真伪。

## 四、防刷与复现机制（抄作业清单）

1. 管线抄harness：Benchmark进Docker版本化 + 模型uv单文件server + serve/run/merge三命令。
2. 契约抄XPolicyLab：观测/动作/轨迹统一schema + predict/reset/batch最小接口。
3. 盲测：测试种子不公开 + 隐藏layout + 跨本体全量测（缺一不上榜）。
4. 存证：录像 + 原始数据存档 + 配置checkpoint全公开 + 一次申诉复测。
5. 认知预筛（可选）：RoboBench MCQ便宜筛，规划DAG精评，降低全量仿真成本。

## 五、语料定位（只做训练源，不当成绩）

- AgiBot World（100万轨/双臂人形/HDF5→LeRobot）：key_frame可挖任务定义，需自补检测器；CC BY-NC-SA禁商用。
- DROID（76k/Franka/RLDS）：最适合预训练 + 鲁棒源；转评测需复刻硬件。
- BridgeV2（60k/WidowX/TFRecord）：最易复现的桌面基线层；任务粒度小。
- OXE（100万+/跨本体/RLDS）：跨本体迁移测试源，噪声大，必须叠基准才有可比性。
